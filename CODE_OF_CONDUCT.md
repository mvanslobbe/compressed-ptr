# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be kind, and assume good faith. Criticise code and
ideas, not people. Harassment, insults, personal or political attacks, and
publishing other people's private information are not acceptable, in the
issue tracker, in pull requests, or anywhere else you represent the
project.

## Reporting

If someone's behaviour concerns you, contact the maintainers privately
through GitHub (for example, open a private security advisory titled
"Code of conduct" if no other private channel is available). Reports are
handled confidentially. The maintainers may remove comments, commits and
other contributions that break this code, and may ban contributors who do
so repeatedly, following the enforcement guidelines of the Contributor
Covenant.
