cptr::detail::basic_ordered_map

The class behind cptr::ordered_map; use that alias. Its members behave like those of std::map.

Synopsis

Declared in <cptr/ordered_map.hpp>

template<
    class K,
    class V,
    class Compare,
    class Cage,
    bool Compressed>
class basic_ordered_map;

Description

The map behind cptr::ordered_map. Compressed = false gives the same tree with raw 8-byte links, which the benchmarks compare against.

A red-black tree with parent links. A header node in the cage holds the root, the leftmost and the rightmost node, and serves as end(), so iterators are a single node pointer and the map object can live anywhere.
